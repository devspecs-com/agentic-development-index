# Project Charter

## Mission

Make the durable context layer of AI-assisted software development easier to understand, compare, verify, and improve.

## Audience

- Developers choosing how to preserve context across coding-agent sessions.
- Teams defining intent, evidence, decision, and handoff practices.
- Tool maintainers explaining their capabilities accurately.
- Researchers studying specifications, development artifacts, context systems, and agent workflows.

## Scope

The index covers artifacts, knowledge, tools, datasets, and benchmarks that materially help with at least one of these jobs:

- preserve why a change exists;
- recover current work state;
- ground an agent in repository evidence;
- bound implementation scope;
- record decisions, validation, and next actions;
- transfer useful state between humans, sessions, agents, or repositories;
- evaluate how well a system performs those jobs.

## Non-Goals

The project is not:

- a comprehensive directory of AI coding products;
- a list of models, generic agent frameworks, or consumer assistants;
- an endorsement program or paid marketplace;
- a synthetic overall leaderboard;
- a source of scraped or unlicensed specification corpora;
- an independent foundation while governance remains controlled by DevSpecs.

## Independence And Affiliation

DevSpecs funds and maintains the project initially. That relationship is disclosed in the repository and generated site. DevSpecs receives no automatic ranking, featured placement, or relaxed evidence requirements.

The project may move to a dedicated organization only after independent contribution and citation are real. Repository location does not substitute for independent governance.

## Product Boundary

The index may link to DevSpecs where editorially relevant. It must remain useful to a reader who never installs DevSpecs.

## Publication Boundary

This repository owns index records, editorial content, schemas, evidence, generation, and exports. `devspecs-website` owns integration at `https://www.devspecs.com/index/`, shared site chrome, consent, and analytics.

## Success Signals

Success is measured through:

- maintainers correcting and verifying their profiles;
- independent contributors improving records and methodology;
- external references to formats, data, or reports;
- non-brand search discovery;
- researchers reusing the structured exports;
- reproducible evaluations that remain useful even when results are unfavorable to DevSpecs.

Raw page count and self-authored backlinks are not success signals.
