# Agentic Development Index v0.1.0

The first release establishes a GitHub-native reference for the durable context layer of AI-assisted software development.

## Included

- 11 format profiles covering intent, instructions, execution, evidence, and continuity.
- 5 practical guides for context recovery, asynchronous agent work, brownfield development, and iteration gates.
- 20 tool profiles spanning repository context, durable instructions, intent and execution, and session provenance.
- Visible evidence labels, limitations, verification dates, affiliation disclosure, and correction workflows.
- Deterministic validation for record structure, category coverage, local navigation, and external source links.

## Explicit Omissions

- No overall ranking, synthetic score, or declared winner.
- No Dataset or Benchmark inventory before those roadmap gates are met.
- No claim that project-reported behavior has been independently reproduced.
- No companion website, generated profile database, paid placement, or required backlink.

## Verification

The release candidate passes from a clean checkout with:

```bash
npm ci
npm test
npm run validate
npm run qa:links
```

At initial branch review, the catalog has zero maintainer confirmations and zero independent factual reviews. See [external review status](../REVIEWS.md) for the current public count.

## Feedback

Use the repository forms to correct a fact, dispute a classification, verify a maintained profile, or propose a new record. Every record remains ordinary Markdown and can be corrected or reverted without a deployment rollback.
