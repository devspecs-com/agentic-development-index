# Hosted session memory

## What It Does

The fixture captures agent sessions and exposes their histories through a hosted interface.

## Where It Fits

It represents session continuity rather than a repository-owned specification or task lifecycle.

## Deployment And Storage

The fixture uses an editor integration and stores captured state in a cloud service.

## Agent Support

The project-reported documentation names one editor agent and a generic extension path.

## Capabilities

The fixture illustrates session capture, memory, and later review.

## Limitations

The fixture does not establish a local export or offline operating mode.
