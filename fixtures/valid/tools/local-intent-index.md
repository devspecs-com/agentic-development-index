# Local intent index

## What It Does

The fixture indexes selected repository files and returns evidence for a supplied topic.

## Where It Fits

It represents repository context and intent recovery rather than model-hosted conversational memory.

## Deployment And Storage

The fixture runs as a local CLI and stores its index in a local database.

## Agent Support

External agents can call the same CLI commands, so the fixture is orchestration-agnostic.

## Capabilities

The cited documentation reports local indexing, retrieval, and repository navigation.

## Limitations

This is a validation fixture, not a production profile or recommendation.
