# Task slice

## What It Is

A task slice is one bounded attempt inside a larger track of work.

## When To Use It

Use it when handing an agent enough scope to make progress without granting the rest of the roadmap.

## Lifecycle

A slice is planned, attempted, checkpointed, and then promoted, improved, reworked, rolled back, or blocked.

## Agent Use

The agent receives one target, relevant evidence, acceptance checks, and an explicit stopping point.

## Pitfalls

Using slices for trivial edits creates ceremony without improving scope control or handoff quality.
