# Context and memory

## What You Will Learn

Distinguish current working context from durable state retained for later sessions.

## Why It Matters

Conflating retrieval and memory makes it difficult to evaluate why an agent saw a fact or carried it forward.

## Workflow

Identify durable repository evidence first, then select the bounded subset needed for the current action.

## Tradeoffs

More retained state can improve continuity while increasing noise and stale-instruction risk.
